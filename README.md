A pure-stdlib Python program that writes one joke about office life, a single line under 200 characters, to `/output/entry.txt`: the office plant is the best-treated "employee" in the building.

> The office plant is the only one here who gets watered, praised, and never asked to work weekends.

## Run it

```sh
python3 main.py entry.txt
```
